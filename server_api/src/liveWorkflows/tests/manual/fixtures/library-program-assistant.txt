Library Program Assistant

Help residents register for library programs. Schedule rooms, maintain attendance spreadsheets, and prepare accessible event notices. Explain program information clearly and respectfully to visitors. Work with colleagues to resolve scheduling problems.

A bachelor's degree is preferred, not required. Equivalent experience from employment, volunteering, or community activities is welcome. Applicants should demonstrate organization, basic spreadsheet skills, and clear communication. Training on the library's booking system is provided.

Location: New Jersey, USA.
