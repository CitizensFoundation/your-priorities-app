# Custom scripts

The scripts in this directory are custom to the nesta-your-priorities codebase. They don't exist in the upstream Your Priorities repository, from which this one was forked. All the other scripts in `server_api/src/scripts` come from upstream.

| Script | Purpose |
|---|---|
| `createCommunityAndGroup.ts` | Creates a community, and within it the group that the landing page links to. Helper for setting up a local development environment. |
